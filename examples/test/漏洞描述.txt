cleo is a PyPI package that provides a command-line interface toolkit for building beautiful and complex command-line applications. It offers various features such as interactive input, output styling, and table rendering. However, cleo is vulnerable to a Regular Expression Denial of Service (ReDoS) attack.
The vulnerability in cleo arises from the Table.set_rows method, which can be exploited by an attacker to trigger an exponential ReDoS attack. By supplying arbitrary input to this method, an attacker can cause the application to enter a state of high CPU usage, leading to a denial of service condition. This vulnerability has a CVSS score of 5.9, indicating a moderate severity level.
