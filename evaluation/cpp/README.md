# C/C++ scope

The [NimBLE case](../../examples/c_cpp_case/CVE-2026-45813/README.md) demonstrates
qualitative application of VulnSight on a C-language vulnerability case. It is not
used as quantitative evaluation. No C/C++ benchmark accuracy is claimed.

The vulnerability description supplied to the model contains vulnerability facts
and the advisory range, without expected verdicts for the target or control.
The recorded output is separate from the input description. This separation alone
does not establish the absence of every possible form of label leakage.
